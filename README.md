# normrest

Norm CSV/TSV rest tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/normrest/

## Install / run

```bash
git clone https://github.com/theworker02/normrest.git
cd normrest
node src/cli.js
node --test
```
